# HighRefreshratePluginForTohouProject

东方Project（D3D9 定步长引擎）通用高刷新率插件。本体是一个 32 位 `d3d9.dll` 代理：放进游戏目录即可让游戏逻辑跟随显示器刷新率运行（120/144/165/240/360/400Hz 均可）。附带一个整合注入器，可同时开关「高刷新率」与「全向移动」两个插件。

当前内置游戏 profile：**TH15 东方绀珠传**（日文 1.00b 实测；汉化版及其他修订号只要不改动代码站点即可自动识别，见下节）。

## 通用机制与支持边界（重要）

插件**不校验 exe 文件名、大小或整文件哈希**，识别方式是运行时逐字节比对游戏代码段中一批"冻结签名"（TH15 profile 共 64 处，覆盖帧调度、更新链表、速度写入、输入、回放等关键站点）：

- 运行时基址与该 profile 的 PE 首选基址一致，且**全部签名匹配** → 安装补丁；
- 任一签名不符、或映像不在支持列表 → **一个字节都不改写**，DLL 退化为完全透明的 d3d9 代理，游戏按原样运行（加壳映像代码尚未解密时会自动等待重试）。

因此语言版本、汉化补丁、exe 修订号的差别不会被拦在门外；但这也意味着它**不是"任意游戏开箱即用"**：逻辑级高刷需要改写游戏内部的固定步长调度、更新链表、回放与输入结构，这些地址每个游戏都不同，必须逐个逆向并做成 profile。新增一款游戏 = 逆向其引擎站点 + 新增一个 profile 注册进插件，无法靠通用扫描自动完成。当前注册表只含 TH15；在其他游戏中它只会安静地做透明代理。

## 它能做什么

- **逻辑高刷**：不只是解锁帧率上限，游戏的移动、弹幕、判定整体按显示器刷新率子步进（Bresenham 定步长调度），高刷下移动和擦弹更顺滑；
- **子 tick 输入**：方向与低速（focus）在每个子 tick 实时采样，斜向走位、擦弹精度跟随真实刷新率；
- **敌机视觉插值**：敌机/精灵在逻辑帧之间平滑插值（纯视觉，不影响判定与随机流）；
- **回放兼容**：高刷录制的回放以记录时的逻辑率播放，逐 tick 输入一并存入回放扩展块；原版回放自动按 60Hz 播放；
- **可选擦弹表现**：高密度擦弹时的子弹着色与自机辉光可在 ini 中关闭（默认保持原版）；
- 不修改游戏 exe 文件，仅靠 DLL 代理与运行时事务补丁（预检失败则零写入）。

## 快速使用（推荐：整合注入器）

1. 双击 `TH_PluginInjector.exe`；
2. 点「浏览」选择 `th15.exe` 所在的游戏目录（选择会被记住）；
3. 勾选「启用高刷新率插件」和/或「启用全向移动插件」；
4. 点「应用开关」，或「应用并启动游戏」直接开玩。

停用插件时注入器只把文件改名为 `*.hfr-off` 备份（不删除），再次勾选即可还原。
**切换前请先退出游戏**——运行中的进程会锁定 DLL。

注入器的插件载荷放在同目录的 `plugins\` 下：

```
plugins\hfr\d3d9.dll, hfr.ini            高刷新率插件
plugins\omni\dinput8.dll, padhook.ini    全向移动插件（帧率自适应版）
```

## 手动安装

把 `plugins\hfr\` 里的 `d3d9.dll`、`hfr.ini` 复制到 `th15.exe` 同目录即可。删除 `d3d9.dll` 即完全卸载。
若同时使用全向移动插件，再把 `plugins\omni\` 里的两个文件复制到同目录；两个 DLL 代理（d3d9 / dinput8）互不冲突。

## 配置（hfr.ini）

插件启动时优先读取游戏目录下的 `hfr.ini`；为兼容旧版本，若不存在则回退读取旧名 `th15_hfr.ini`（日志固定写 `hfr.log`）。

| 键 | 默认 | 说明 |
|---|---|---|
| `fps` | `0` | 目标呈现率，0 = 自动检测显示器刷新率 |
| `substep` | `1` | 游戏逻辑子步进（高刷核心） |
| `subtick_input` | `1` | 方向/focus 按显示率采样 |
| `enemy_interp` | `1` | 敌机/精灵视觉插值 |
| `graze_bullets` / `graze_glow` | `1` | 擦弹着色 / 自机辉光表现，置 0 可关闭 |
| `debug` | `0` | 写诊断日志 `hfr.log`（排查问题时设 1） |

识别/安装结果均可在游戏目录的 `hfr.log` 中查看；未识别的映像会明确记录"仅做透明 d3d9 代理"。

## 目录说明

- `TH_PluginInjector.exe` —— 高刷 + 全向移动 整合开关/启动器
- `plugins\` —— 两个插件的安装载荷
- `injector_src\` —— 注入器源码（纯 Win32 C，`build.bat` 用 32 位 MinGW 编译）

## 注意

- 逻辑补丁在 TH15（日文 1.00b）上实机验证（含 400Hz 实战弹幕）；其他 TH 作品需要新增 profile 后才会生效。
- 若汉化/改版修改了被冻结的代码站点，签名校验会失败并安全禁用（透明代理），不会损坏游戏；这是有意的保护而非缺陷。
- 建议用全屏独占或无边框窗口；刷新率在游戏启动时检测，切换显示器后重启游戏。
- 与第三方手柄插件（dinput8.dll）可共存。
