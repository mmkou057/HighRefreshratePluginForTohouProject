# HighRefreshratePluginForTohouProject

东方Project（D3D9 定步长引擎）通用高刷新率插件。本体是一个 32 位 `d3d9.dll` 代理：放进游戏目录即可让游戏逻辑跟随显示器刷新率运行（120/144/165/240/360/400Hz 均可）。附带整合注入器 `PluginSwitch.exe`，可同时开关「高刷新率」「全向移动」「轨迹可视化（调试）」三个插件。

当前内置游戏 profile：**TH10 ~ TH18**（TH10 风神录 / TH11 地灵殿 / TH12 星莲船 / TH13 神灵庙 / TH14 辉针城 / TH15 绀珠传 / TH16 天空璋 / TH17 鬼形兽 / TH18 虹龙洞）。TH08 及更早作品为不同世代引擎，不在支持范围内（见下节）。

## 通用机制与支持边界（重要）

插件**不校验 exe 文件名、大小或整文件哈希**，识别方式是运行时逐字节比对游戏代码段中一批"冻结签名"（每个 profile 数十处，覆盖帧调度、更新链表、速度写入、输入、回放等关键站点）：

- 运行时基址与该 profile 的 PE 首选基址一致，且**全部签名匹配** → 安装补丁；
- 任一签名不符、或映像不在支持列表 → **一个字节都不改写**，DLL 退化为完全透明的 d3d9 代理，游戏按原样运行（加壳映像代码尚未解密时会自动等待重试）。

因此语言版本、汉化补丁、exe 修订号的差别不会被拦在门外；但这也意味着它**不是"任意游戏开箱即用"**：逻辑级高刷需要改写游戏内部的固定步长调度、更新链表、回放与输入结构，这些地址每个游戏都不同，必须逐个逆向并做成 profile。新增一款游戏 = 逆向其引擎站点 + 新增一个 profile 注册进插件，无法靠通用扫描自动完成。

**已验证情况**：TH15（400Hz 实战弹幕）、TH17、TH18、TH16、TH11/TH12 均已实机验证（hfr.log 识别成功、主菜单与关卡稳定）；TH10/TH13/TH14 为同族布局 profile（自动识别，未逐作实测）。TH08 永夜抄经逆向评估为 d3d8+FPU 老世代单体引擎（无统一速度全局、无 runner 链表），家族运行时不适用，宣告不支持。

## 它能做什么

- **逻辑高刷**：不只是解锁帧率上限，游戏的移动、弹幕、判定整体按显示器刷新率子步进（Bresenham 定步长调度），高刷下移动和擦弹更顺滑；
- **子 tick 输入**：方向与低速（focus）在每个子 tick 实时采样，斜向走位、擦弹精度跟随真实刷新率；
- **敌机视觉插值**：敌机/精灵在逻辑帧之间平滑插值（纯视觉，不影响判定与随机流）；
- **回放兼容**：高刷录制的回放以记录时的逻辑率播放，逐 tick 输入一并存入回放扩展块；原版回放自动按 60Hz 播放；
- **可选擦弹表现**：高密度擦弹时的子弹着色与自机辉光可在 ini 中关闭（默认保持原版）；
- 不修改游戏 exe 文件，仅靠 DLL 代理与运行时事务补丁（预检失败则零写入）。

## 快速使用（推荐：整合注入器）

1. 双击 `PluginSwitch.exe`（必须与 `plugins\` 同目录）；
2. 下拉框选游戏（自动扫描相邻目录）或 [浏览...] 选任意 `th*.exe`；
3. 勾选要启用的插件 → 立即部署；取消勾选 → 立即停用；
4. [启动游戏] 直接开玩，[打开游戏目录] 可查看日志。

停用插件时注入器只把文件改名为 `*.off` 备份（不删除），再次勾选即可还原。
**切换前请先退出游戏**——运行中的进程会锁定 DLL。

注入器的插件载荷放在同目录的 `plugins\` 下：

```
plugins\hfr\d3d9.dll, hfr.ini            高刷新率插件（TH10~TH18）
plugins\omni\dinput8.dll, padhook.ini    全向移动插件（极坐标矢量直映版，mode=4）
plugins\traj\traj.dll                    轨迹可视化（调试，由注入器远程注入）
```

## 手动安装

把 `plugins\hfr\` 里的 `d3d9.dll`、`hfr.ini` 复制到游戏主程序（`thXX.exe`）同目录即可。删除 `d3d9.dll` 即完全卸载。
若同时使用全向移动插件，再把 `plugins\omni\` 里的两个文件复制到同目录；两个 DLL 代理（d3d9 / dinput8）互不冲突。轨迹可视化由注入器远程注入，手动安装不加载。

## 配置（hfr.ini）

插件启动时优先读取游戏目录下的 `hfr.ini`；若不存在则回退读取旧名 `th15_hfr.ini`（日志固定写 `hfr.log`）。

| 键 | 默认 | 说明 |
|---|---|---|
| `fps` | `0` | 目标呈现率，0 = 自动检测显示器刷新率 |
| `substep` | `1` | 游戏逻辑子步进（高刷核心） |
| `subtick_input` | `1` | 方向/focus 按显示率采样 |
| `enemy_interp` | `1` | 敌机/精灵视觉插值 |
| `graze_bullets` / `graze_glow` | `1` | 擦弹着色 / 自机辉光表现，置 0 可关闭 |
| `debug` | `0` | 写诊断日志 `hfr.log`（排查问题时设 1） |

识别/安装结果均可在游戏目录的 `hfr.log` 中查看；未识别的映像会明确记录"仅做透明 d3d9 代理"。

## 目录说明

- `PluginSwitch.exe` —— 三插件整合开关/启动器（32 位，枚举游戏进程用）
- `plugins\` —— 三个插件的安装载荷
- `injector_src\` —— 注入器源码（C# WinForms，`build.bat` 用系统自带 .NET Framework csc 编译 x86）

## 注意

- 逻辑补丁在 TH15/TH17/TH18/TH16/TH11/TH12 实机验证；TH10/TH13/TH14 为同族布局自动识别。
- 若汉化/改版修改了被冻结的代码站点，签名校验会失败并安全禁用（透明代理），不会损坏游戏；这是有意的保护而非缺陷。
- 建议用全屏独占或无边框窗口；刷新率在游戏启动时检测，切换显示器后重启游戏。
- 与第三方手柄插件（dinput8.dll）可共存。
